# LoveBytes.

Watch movies, YouTube videos, and shared media with friends in real time.

This project is being built publicly as a learning journey into backend engineering, distributed systems, real-time communication, and Spring Boot.

## Vision

Create an experience that feels like sitting next to someone while watching content together.

Planned features:

* Room creation and invitations
* Real-time chat
* Synchronized play/pause/seek
* YouTube Watch Together
* Voice notes
* User presence indicators
* Video calls
* Screen sharing
* WebRTC peer-to-peer communication
* End-to-end encrypted messaging
* End-to-end encrypted voice and video
* Multi-user watch rooms

## Tech Stack

Backend:

* Java 21
* Spring Boot
* PostgreSQL
* WebSocket
* Spring Security
* JWT

Frontend:

* React

Future:

* WebRTC
* Redis
* Docker
* CI/CD

## Current Status

Early development.

The project is being built incrementally with a focus on learning software engineering fundamentals before optimization and large-scale architecture.
